# 智行天下 - 大学生智能旅游服务平台

## 项目简介

智行天下是专为大学生群体打造的智能旅游服务平台，以"AI规划+社交组队+攻略整合"为核心功能，实现了旅游景点点评、攻略分享、AI智能线路规划、景区门票优惠券秒杀等功能。

## 技术栈

- **后端框架**：Spring Boot 2.7.17
- **AI框架**：LangChain4j
- **持久层**：MyBatis-Plus 3.4.3
- **数据库**：MySQL 8.0.33
- **缓存**：Redis
- **消息队列**：RabbitMQ
- **反向代理**：Nginx
- **定时任务**：Spring Task
- **工具库**：Hutool、Lombok

## 核心功能

### 1. 旅游景点管理
- 景点信息展示与搜索
- 景点分类管理
- 景点点评与评分

### 2. 攻略分享系统
- 旅游攻略发布与管理
- 攻略评论与点赞
- 热门攻略推荐

### 3. AI智能线路规划
- 基于阿里云百炼平台大模型
- 结合用户偏好智能生成旅游线路
- 多日行程自动规划

### 4. 优惠券秒杀系统
- 景区门票优惠券管理
- 高并发秒杀功能
- 一人一单限制

### 5. 社交组队功能
- 用户关注与粉丝系统
- 旅游组队信息发布
- 社交互动功能

## 技术亮点

1. **高性能缓存设计**
   - 使用Redis对高频访问的景点信息和攻略信息进行缓存
   - 解决了高并发场景下的缓存穿透、雪崩、击穿问题
   - 提升了数据并发下的安全性

2. **AI智能规划**
   - 接入阿里云百炼平台大模型
   - 基于LangChain4j框架使用Prompt提示词和RAG向量库
   - 实现了旅行路线智能规划助手

3. **高并发秒杀保障**
   - 使用Redis存储门票数量
   - 基于Lua脚本判断用户的下单资格
   - 加入乐观锁做保障，保证门票的库存量不超卖和一人一单

4. **异步处理优化**
   - 使用消息队列RabbitMQ，将景点门票优惠券同步下单变为异步下单
   - 使用令牌桶算法进行一定程度上的限流
   - 提升秒杀业务的性能

5. **点赞功能实现**
   - 使用Redis中的Set和ZSet来存储点赞用户id和点赞数量
   - 实现用户攻略以及评论的点赞功能
   - 使用SpringTask定时任务定时移除点赞数最少的，通过MQ异步写入数据库

## 快速开始

### 环境要求

- JDK 1.8+
- MySQL 8.0+
- Redis 6.0+
- RabbitMQ 3.8+
- Maven 3.6+

### 数据库配置

1. 创建数据库：`hema_dp`
2. 导入数据库脚本：`src/main/resources/db/hmdp.sql`
3. 修改数据库连接配置：`src/main/resources/application.yaml`

### 项目启动

1. 克隆项目：
   ```bash
   git clone <项目地址>
   cd zhixing-tianxia
   ```

2. 安装依赖：
   ```bash
   mvn clean install
   ```

3. 启动项目：
   ```bash
   mvn spring-boot:run
   ```

4. 访问地址：
   ```
   http://localhost:8081
   ```

3. **秒杀系统**：保证高并发场景下的库存安全
4. **异步处理**：使用消息队列提升系统性能
5. **社交功能**：实现用户互动和内容点赞
